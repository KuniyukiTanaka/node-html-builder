# node-html-builder

## 概要

軽量な静的HTMLのテンプレート/アセットビルドツールです。

## 特徴

- テンプレートEJS・SCSSをパースしてhtmlやcssを出力します。
- プロジェクト内に独自の設定ファイル(build-tmpl.json)を使用し複数のビルドを管理・実行できます。
- ローカルプレビューに対応しオフライン下でも構築結果を確認できます。
- アセットファイルの変更監視、プレビュー即時反映、プレビュー限定設定などの機能を有します

## コアスクリプト

- ビルド制御: run/build-tmpl.js
- ワーカー（ファイル変換/出力）: run/build-worker.js
- おまけ: [画像変換]run/mediacomp.js

## ビルド

- デフォルトビルド:
  - npm run build-tmpl （ファイル監視付き: npm run build-live を併用）
- デモビルド:
  - npm run build-demo
